# 실제 메뉴 데이터 확보 절차

> 작성일: 2026-08-21

## 원칙

실제 메뉴 데이터는 메뉴명, 판매 가격, 해당 지점, 확인일, 출처를 함께 확인한 경우에만 `매장 확인`으로 등록한다. 검색 결과나 다른 지점의 가격은 해당 매장의 실제 가격으로 간주하지 않는다.

## 데이터 신뢰도

| 값 | 의미 | AI 처리 |
|---|---|---|
| `store-verified` | 해당 매장에 직접 확인 | 높은 신뢰도 |
| `brand-official` | 브랜드 공식 메뉴, 지점 가격 미확인 | 중간 신뢰도와 경고 |
| `name-derived` | 가게명으로 추정 | 중간 이하 신뢰도와 경고 |
| `category-derived` | 업종으로 추정 | 낮은 신뢰도와 경고 |
| `unverified` | 판단 근거 없음 | 추천 제외 |

## 현재 확보 방식

카카오 로컬 API는 장소명, 주소, 전화번호, 좌표, 카카오맵 장소 링크를 제공하지만 메뉴와 가격은 제공하지 않는다. 따라서 메뉴는 다음 순서로 확인한다.

1. `npm run menu-queue`로 지역별 우선 확인 매장 목록 생성
2. 해당 매장 전화, 매장 공식 채널 또는 현장 메뉴판으로 확인
3. 메뉴명·가격·확인일·출처를 `data/verified-menus.json`에 등록
4. `npm run apply-verified-menus`로 형식과 매장 ID 검증 후 앱 데이터에 적용
5. `npm run validate-ai`, `npm run lint`, `npm run build` 실행

## 확인 질문

- 현재 판매 중인 1인 식사 메뉴 이름과 가격
- 급식카드로 결제 가능한 메뉴인지
- 매장 식사와 포장 가격이 같은지
- 최소 주문 또는 세트 전용 조건이 있는지
- 가격이 적용되는 기준일

## 입력 예시

```json
{
  "storeId": "가맹점-id",
  "sourceType": "store-confirmed",
  "sourceUrl": null,
  "verifiedAt": "2026-08-21T09:00:00+09:00",
  "note": "매장 전화 확인",
  "menu": [
    { "name": "김밥", "price": 3500 },
    { "name": "참치김밥", "price": 4500 }
  ]
}
```

가격이나 판매 여부가 확인되지 않은 항목은 입력하지 않는다. 매장 확인 데이터도 시간이 지나면 바뀔 수 있으므로 화면에 확인일을 표시하고 정기적으로 재검증한다.
