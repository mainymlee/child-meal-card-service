# 결식아동 급식카드 지원 서비스 기획서 (가칭)

## 1. 프로젝트 개요

**한 줄 소개**
> 전국적으로 매년 171억 원 규모(충전금의 7.8%)가 쓰이지 못하고 사라지는 결식아동 급식카드 문제를, 이용 장벽을 낮추고 잔액을 직접 챙겨주는 방식으로 줄이는 서비스

**타겟 지역**: 강원특별자치도 (춘천시 중심)

**작성일**: 2026-08-11 (최초) · 2026-08-14 (개정 — 핵심 문제를 "소진 실패" 하나로 통합하고 정부 실태조사 출처 확보)

---

## 2. 문제 정의

### 2-1. 핵심 문제

> 결식아동에게 지급된 급식카드 충전금 중 상당액이 한 해 안에 다 쓰이지 못하고 소멸한다.

국무조정실 정부합동 부패예방추진단과 보건복지부가 2025년 11월~2026년 4월 전국 182개 지방자치단체를 대상으로 실시해 2026년 6월 24일 발표한 「결식아동 급식카드 운영실태 조사」 결과다.

- 2024년 기준 미사용 소멸액이 **약 171억 원**, 전체 충전금액의 **약 7.8%**.
- 충전금액의 **10% 미만**만 사용한 아동이 전국 약 **4,800명**.
- 미사용 소멸의 주된 원인으로 **낙인감 우려**와 **사용 방법 미숙지**가 꼽힘.

전국 단위 조사이며, 강원도·춘천시로 좁힌 별도 수치는 아직 확인되지 않았다 (9장 1번 참고).

### 2-2. 왜 다 못 쓰는가 — 원인

위 정부 조사와 원주투데이 등 언론 보도를 종합하면, 원인은 하나로 모인다 — **아이가 카드를 편하게 쓸 방법을 모르거나, 쓰는 것 자체가 부담스럽다.**

- **낙인감 우려**: 혼자 음식점에 들어가 카드를 내미는 것이 부담스러움 (정부 조사·원주투데이 공통 확인)
- **정보 접근성 부족**: 어디서 쓸 수 있는지 바로 확인하기 어려움. 기존 전용 앱(나비얌)의 정보 오류로 안내된 가맹점인데도 실제 이용이 불가능한 사례도 반복됨
- **시간대 제약**: 방학·주말·야간에는 일반 음식점이 문을 닫아 선택지가 좁아짐

원주투데이 기사는 지원 금액 규모보다 **이용 구조 개선**이 더 중요하다고 강조한다.

### 2-3. 방증 — 편의점 편중 현상

이 "이용 장벽" 가설을 뒷받침하는 방증이 있다. 아이들이 그나마 쓰는 돈도 편의점에 쏠린다는 것이다.

| 지역 | 연도 | 편의점 이용 비중 |
|---|---|---|
| 강원도 전체 | 2021년 | 62.8% |
| 춘천시 | 2025년 | 39.7% (한식 16.5%, 일반음식 12%, 패스트푸드 8.8%) |
| 원주시 | 2025년 | 35% (한식·일반음식점 20%, 기타 10% 내외) |
| 참고: 인천시 | 2025년 → 2026년 1분기 | 54.2% → 48.7% |

춘천시 공공데이터(아동급식카드 가맹점 현황, 2025-07-14 기준, 총 4,593개소)를 보면 가맹점 자체는 한식(54.2%)·일반대중음식(22.5%) 위주로 충분히 존재하고 편의점은 8.7%뿐이다. **가맹점 수로는 편의점이 8.7%인데 실제 이용은 39.7%(춘천)** — "가맹점이 없어서"가 아니라 "찾아 이용하기 번거로워서" 편의점으로 몰린다는 뜻이다.

즉 "돈을 아예 못 쓰는 것"(2-1)과 "쓰는 돈이 편의점에 쏠리는 것"(2-3)은 같은 이용 장벽이 다르게 나타난 결과로 볼 수 있다.

## 3. 타겟 사용자 (페르소나)

**김지민(가상 인물), 11세, 춘천시 후평동 거주 초등학생.**
한부모 가정으로 급식카드 대상자. 부모가 오후·저녁 근무를 해 방과후·주말·방학 중 혼자 끼니를 해결해야 한다. 매번 가맹점을 검색하기 귀찮아 습관적으로 집 앞 편의점에서 삼각김밥·컵라면으로 때운다. 카드에 얼마가 남았는지도 잘 모른다.

## 4. 핵심 기능

모든 기능의 목적은 하나다 — **이용 장벽을 낮춰서 카드를 실제로, 다 쓰게 만드는 것.** 서비스는 **지도**와 **챗봇** 두 축으로 구성된다.

### 기능 1 — 급식카드 소멸 알림 (챗봇)

2-1 핵심 문제에 직접 대응하는 기능이다. 매달 초 사용자가 직접 입력한 현재 잔액을 기준으로, 이번 달 안에 다 쓰지 못하면 소멸되는 금액과 하루 권장 사용액을 계산해 알려준다. 카드사 실시간 연동이 없어 자동 조회는 하지 못하므로, 수기로 입력한 값을 기준으로 계산한다.

### 기능 2 — AI영양사 (챗봇 + 지도)

이용 장벽(낙인감·시간대 제약)을 낮춰서 "잔액이 있는데도 못 쓰는" 상황을 줄이는 기능이다. 가맹점 메뉴 중 편의점 간편식 대신 영양 균형 메뉴(백반, 국밥 등)를 우선 추천하되, 다음 상황 정보를 먼저 반영해 **실제로 갈 수 있는 곳 중에서** 추천한다.

- **현재 시간**: 지금 문을 연 가맹점만 추천 대상으로 삼는다.
- **매장식사 / 포장**: 사용자가 선택한 방식에 맞는 가게만 추천한다.
- **혼밥 여부**: 혼자 먹는다고 답하면 포장·카운터 주문처럼 낙인감 부담이 적은 방식을 우선 추천하고, 같이 먹는다고 답하면 매장식사 옵션도 함께 보여준다.

시간·매장/포장·혼밥여부로 먼저 "갈 수 있는 곳"을 걸러낸 뒤, 그 안에서 영양 균형으로 순위를 매기는 2단계 구조다. 추천받은 가게는 지도의 가맹점 상세 화면으로 연결되어, 지도로 직접 찾아보는 경로와 챗봇 추천 경로가 하나의 상세 화면에서 만난다.

### 기능 3 — 가맹점 안내 (지도)

현재 위치 기준 급식카드 가맹점을 지도에서 직접 탐색한다. 기능 2의 추천 결과와 같은 데이터·같은 상세 화면을 공유한다.

### 기능 4 — 복지·서비스 안내 (챗봇, 부가 기능)

춘천시 복지 사이트(https://www.chuncheon.go.kr/new-welfare/main/)를 기반으로 페르소나 조건(한부모가정·아동 등)과 관련 있는 복지 제도를 찾아 추천한다. **핵심 문제(소진 실패)와 직접 연결되는 기능은 아니며**, 별도 가치로 붙이는 부가 기능이다. 신청·접수는 대행하지 않고 안내까지만 한다 (5장 참고).

## 5. 하지 않을 것 (Non-goals)

1. **카드 발급·신청 대행** — 기존 행정 절차는 그대로 유지한다.
2. **결제·포인트 충전 기능** — 기존 카드사 결제 시스템을 그대로 활용한다.
3. **보호자·교사용 실시간 감시 기능** — 아동의 소비 내역을 어른이 들여다보는 기능은 넣지 않는다 (낙인·사생활 침해 방지).
4. **복지 신청·접수 대행** — 복지 제도 정보 안내·매칭까지만 하고, 실제 신청은 각 기관 절차를 그대로 따른다.
5. **카드사 실시간 잔액 자동 조회** — 사용자가 직접 입력한 값을 기준으로 계산한다.

## 6. 화면 흐름 (초안 — 검토 필요)

핵심 과업을 완료하는 최소 화면 구성이다. 챗봇이 여러 역할을 겸하게 되면서 생긴 분기는 아직 초안 수준이라 검토가 필요하다.

| 순서 | 화면 이름 | 사용자가 하는 일 | 다음 화면 |
|---|---|---|---|
| 1 | 홈 화면 | "이번 달 잔액 확인" / "오늘 뭐 먹지?" / "복지 혜택 확인" 중 선택하거나 챗봇에 자유롭게 질문 | 목적에 따라 6 · 2 · 5 화면 중 하나 |
| 2 | 추천 결과 화면 | 지도 + 균형 메뉴 추천 리스트 확인 후 선택 (혼밥여부·매장/포장은 챗봇 대화 중 확인) | 가맹점 상세 화면 |
| 3 | 가맹점 상세 화면 | 메뉴·거리·영업시간 확인 후 "길찾기" 클릭 | 길안내 화면 |
| 4 (선택) | 챗봇 대화 화면 | 잔액 확인 · AI영양사 추천 · 복지안내 중 무엇이든 대화로 요청 (홈 화면의 대안 경로) | 목적에 따라 6 · 2 · 5 화면 중 하나 |
| 5 | 복지 안내 결과 화면 | 추천된 복지 제도 목록·조건 확인 | 정보 확인 후 종료 또는 외부 링크 |
| 6 | 잔액 확인/입력 화면 | 현재 잔액 수기 입력, 소진 예측 확인 | 홈 화면 |

## 7. 화면 구조 (초안 — 검토 필요)

화면마다 **사용자 / AI / 데이터**를 정리한다.

### 화면 1 — 홈 화면

- **사용자**: 잔액 확인·메뉴 추천·복지 안내 중 선택하거나 챗봇에 직접 질문 입력
- **AI**: 챗봇 질의 의도 해석(잔액·AI영양사·복지안내 중 판별), 사용자 위치 기반 주변 가맹점 여부 파악
- **데이터**: 사용자 현재 위치(GPS), 수기 입력된 잔액, 최근 대화 기록

### 화면 2 — 추천 결과 화면
- **사용자**: 지도·리스트에서 추천 가맹점·메뉴 확인 후 하나 선택, 혼밥여부·매장/포장 응답
- **AI**: 가맹점 실시간 영업 여부·거리 계산, 혼밥여부·매장/포장 선택으로 1차 필터링 후 최근 섭취 기록 기반 영양 균형 메뉴로 정렬·추천
- **데이터**: 가맹점 위치·영업시간·메뉴 DB, 사용자 최근 섭취 기록, 영양 기준 데이터, 사용자가 답한 혼밥여부·매장/포장 선택

### 화면 3 — 가맹점 상세 화면
- **사용자**: 메뉴·거리·영업시간 확인 후 "길찾기" 클릭
- **AI**: 실시간 경로 안내, 방문 후 먹은 메뉴 기록 제안 (다음 추천 정확도 향상용)
- **데이터**: 가맹점 상세 정보(메뉴, 사진), 경로 데이터, 섭취 기록 업데이트

### 화면 5 — 복지 안내 결과 화면
- **사용자**: 추천된 복지 제도 목록에서 관심 있는 항목 확인
- **AI**: 페르소나 조건(한부모가정, 연령 등)에 맞는 복지 제도 매칭
- **데이터**: 춘천시 복지 사이트 기반 제도 정보(수집 방식 확인 필요), 사용자 가구 상황 프로필(수집 시점·방법 미정)

### 화면 6 — 잔액 확인/입력 화면
- **사용자**: 현재 잔액 수기 입력·수정, 소진 예측 확인
- **AI**: 입력값과 날짜 기반 하루 권장 사용액 계산, 월말 소멸 예상액 계산, 월초 리마인드
- **데이터**: 사용자가 입력한 잔액, 카드 충전 주기 정보
